# Noire Clothing E-Commerce Website

A front-end clothing e-commerce website developed as a university group project using HTML, CSS and JavaScript.

The project provides a multi-page online shopping interface where users can browse clothing categories, view products and navigate through a simulated purchasing experience.

> **Note:** This is a front-end project. Payments, backend services and real user accounts are not implemented.

## Preview

![Noire Clothing E-Commerce Website](screenshots/Noire%20Home%20Page.png)

## Features

The website includes:

- Clothing product catalogue
- Men's clothing section
- Women's clothing section
- Kids' clothing section
- Shopping cart interface
- Checkout interface
- About page
- Contact page
- Blog
- Responsive layout

## Product Categories

The website separates products into dedicated shopping sections for:

- Men
- Women
- Kids

This provides users with a structured way to browse the available clothing products.

## Shopping Interface

The project includes shopping cart and checkout pages to demonstrate the interface of an e-commerce purchasing process.

These pages simulate the front-end user experience but do not process real transactions.

## How to Run

No installation is required.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

The website will run locally in the browser.

## Project Purpose

This project was developed as part of a university group assignment to practise front-end web development and collaborative project work.

It provided experience building a multi-page e-commerce interface and organising a larger website across multiple pages and assets.
